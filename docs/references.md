# References and credits

Vim Dojo stands on the shoulders of these projects. No code or text was copied
from any of them; we took ideas and credit them here. Licenses as of 2026-10-07.

| Project | License | What inspired us |
| --- | --- | --- |
| [vim-be-good](https://github.com/ThePrimeagen/vim-be-good) by ThePrimeagen and contributors | no license file in the repo | Timed rounds that force moves from memory; a menu and rounds that feel like a game |
| [nvim-training](https://github.com/Weyaaron/nvim-training) by Weyaaron | GPL-3.0 | A broad catalogue of small tasks grouped into topic collections; being strict about how a task is solved |
| vimtutor / Neovim `:Tutor`, by Michael C. Pierce and Robert K. Ware (Colorado School of Mines), modified by Bram Moolenaar, Felipe Morales and Rory Nesbitt | Vim license | The order of the curriculum (lessons 1–3); lines checked against expected text with a ✗/✓ mark |
| [learn-vim](https://github.com/dofy/learn-vim) by dofy and contributors | CC0-1.0 | Grouping motions by size (cell, word, line); "estimate a count, then correct with a small move" |
| [hardtime.nvim](https://github.com/m4xshen/hardtime.nvim) by Max Shen | MIT | Hints naming a better command after an inefficient one; its recommended motion workflow; a report of common bad habits (roadmap) |
| [delaytrain.nvim](https://github.com/ja-ford/delaytrain.nvim) by ja-ford | Apache-2.0 | Gently blocking a key repeated too often within a short window (our optional habit mode) |

Also used while building: [Neovim](https://neovim.io) itself (Apache-2.0 / Vim
license), pinned at 0.12.5.
